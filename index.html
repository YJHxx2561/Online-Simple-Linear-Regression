ABOUT THIS TOOL

什么是一元线性回归？

一元线性回归用于研究一个自变量 X 与一个因变量 Y 之间的线性关系。它在一组散点中找出一条「最合适」的直线，使所有点到这条直线的偏差平方和最小，这条线称为回归直线。

ŷ = b₀ + b₁x
  • b₁ 斜率：X 每增加 1，Y 平均变化多少；正负号表示变化方向。
  • b₀ 截距：X = 0 时 Y 的拟合值；若 0 不在数据范围内，其实际意义有限。
  • ŷ 预测值：把某个 X 代入方程得到的 Y 估计值。

它常用于分析两个量之间的关系（如广告投入与销售额）、根据已知数据做预测，以及通过 R² 判断线性关系解释了多少变异。
